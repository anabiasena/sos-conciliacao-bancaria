# Fluxo Original (Planilha) — substituído por este projeto

1. Baixar os extratos OFX nos bancos.
2. Importar na planilha de fluxo financeiro (Google Sheets).
3. Categorizar as movimentações.
   - Em caso de dúvida, consultar quem realizou a movimentação e categorizar novamente.
4. Conferir se os valores batem com o extrato.
   - Se sim, marcar o período como conciliado.
   - Se não, tratar a divergência e então marcar como conciliado.

Esse processo manual foi substituído pelo painel web + workflow n8n descritos neste repositório.
